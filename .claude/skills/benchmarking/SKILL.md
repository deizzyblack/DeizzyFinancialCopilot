# Skill: Benchmarking

## Description
Compares financial metrics across portfolio companies. Uses approved records from the storage layer to generate cross-company comparison tables and identify outliers. Designed for VC/PE portfolio monitoring use case.

## Trigger
When user wants to compare metrics across companies, or view portfolio-level analytics.

## Scope
- Cross-company metric comparison (Revenue, EBITDA, Net Income by period)
- Outlier detection (values significantly different from peer group)
- Growth rate computation from time-series data
- Uses only APPROVED records for comparison accuracy
- No external data sources — purely internal pipeline data
